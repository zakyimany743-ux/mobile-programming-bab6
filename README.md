# Mobile Programming - Bab 6: State dan Interaksi Pengguna

Source code contoh dari buku *Mobile Programming Menggunakan Flutter dan Visual Studio Code untuk Pemula*.

| Folder | Topik | Konsep utama |
|---|---|---|
| `flutter_state` | Memperbarui tampilan | `setState()`, StatefulWidget |
| `proses_input` | Memproses masukan pengguna | `TextField`, `onChanged` |
| `flutter_callback` | Fungsi callback | `ElevatedButton`, `onPressed` |
| `flutter_animasi` | Animasi | `AnimatedContainer`, `duration`, `curve` |
| `flutter_dinamis` | Tampilan dinamis | `ListView.builder`, `TextEditingController` |

## Cara menjalankan
Setiap folder berisi `lib/main.dart`. Buat project Flutter dengan nama yang sama, lalu ganti isi `lib/main.dart`:

```
flutter create flutter_state
# salin lib/main.dart dari repo ini, lalu:
cd flutter_state
flutter run
```
